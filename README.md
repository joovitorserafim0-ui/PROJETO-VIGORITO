# Projeto: Automação Fandi - Vigorito Chevrolet

**O que é:** Um robô em Python + Selenium para automatizar a consulta de documentos no portal Fandi.

**Problema:** O processo manual levava aproximadamente 4 horas diárias.

**Solução:** Automação que reduz o tempo para **3 minutos**, com tratamento de erros para instabilidades do sistema.

**Tecnologias:** Python, Selenium WebDriver.
